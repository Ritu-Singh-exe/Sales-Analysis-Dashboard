# Sales Analysis Dashboard

## Project Overview

This project presents an interactive Sales Analysis Dashboard developed using Excel, SQL Server, and Power BI. The dashboard provides insights into sales trends, customer value, product performance, regional revenue distribution, and operational efficiency.

The objective of this project is to demonstrate an end-to-end Business Intelligence workflow, from data preparation and analysis to visualization and reporting.

---

## Tools & Technologies

- Microsoft Excel
- SQL Server
- Power BI
- DAX

---

## Dataset Information

The dataset contains transactional sales data including:

- Orders
- Products
- Customers
- Salespersons
- Regions
- Discounts
- Returns
- Shipping Costs
- Delivery Performance

The dataset consists of over 1,500 sales transactions across multiple regions, customer segments, and product categories.

---

## Project Workflow

### 1. Data Preparation in Excel

- Reviewed and validated raw sales data
- Checked for missing values and data inconsistencies
- Verified data types and business fields
- Prepared the dataset for SQL Server import

### 2. Data Analysis in SQL Server

- Imported data into SQL Server
- Performed exploratory data analysis
- Wrote SQL queries to calculate KPIs and business metrics
- Analyzed revenue, products, regions, customers, and returns
- Generated insights used for dashboard development

### 3. Dashboard Development in Power BI

- Connected Power BI to SQL Server
- Created calculated measures using DAX
- Built interactive reports and KPI cards
- Added slicers and filters for dynamic analysis
- Designed a two-page dashboard for executive reporting
